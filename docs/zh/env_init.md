# env_init.sh 使用说明

## 脚本简介
该脚本用于一键初始化开发者的工作环境。主要功能包括：
1. **工作目录配置**：自动创建或配置标准的开发工作目录结构。
2. **字符集配置**：统一系统默认字符集（通常为 UTF-8），避免终端乱码问题。
3. **网络代理配置**：针对国内网络环境，自动配置全局终端代理，加速后续依赖包的下载。

## 运行模式
该脚本支持多种运行模式，通过传入不同的参数 `mode` 控制：
- `env`：仅初始化开发环境（包括字符集和 Workspace）。
- `proxy`：仅配置网络代理环境变量。
- `all`：执行完整的环境与代理初始化（默认行为）。

## 使用示例

### 1. 全量初始化 (默认)
直接执行脚本，默认配置环境与代理：
```bash
./scripts/env_init.sh
# 或者显式声明
./scripts/env_init.sh all
```

### 2. 仅配置系统环境变量
如果您不需要配置代理，仅想初始化基础工作目录：
```bash
./scripts/env_init.sh env
```

### 3. (向后兼容) 直接传递代理地址
脚本也支持传递代理地址作为参数直接初始化代理：
```bash
./scripts/env_init.sh 127.0.0.1:10808
```
