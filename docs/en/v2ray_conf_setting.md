# v2ray_conf_setting.sh Usage Guide

## Introduction
V2Ray client configuration files (JSON) are often structurally complex and prone to errors. This tool provides a command-line based Q&A interactive guide, helping you quickly and flawlessly generate a compliant V2Ray Client proxy configuration file.

## Usage Examples

Enter the tool's interactive generation guide:
```bash
./scripts/tools/v2ray_conf_setting.sh
```
Follow the terminal prompts to input your inbound port, node address, UUID, alter ID, and other key information sequentially. After the script finishes, it will output a standard configuration file named `config.json` in the current directory.
